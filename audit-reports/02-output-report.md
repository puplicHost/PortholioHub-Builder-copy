# تقرير التدقيق العميق — سطح المخرجات العامة (Output / Public)

> نوع التدقيق: قراءة فقط (READ-ONLY). كل بند مدعوم بمرجع `ملف:سطر`.
> مستويات الثقة: **مؤكد** / **مرجّح** / **مشتبه**. الخطورة: Critical/High/Medium/Low. المجال: يمنع/يبطئ/خسارة عمل/أمن/صقل.

## 1) الملخص التنفيذي

سطح المخرجات = الصفحات العامة التي يراها الزائر: الملف الشخصي `/u/[username]`، صفحات المشاريع `/u/[username]/projects/[slug]`، إضافة إلى SEO (`sitemap`, `robots`, صور OG) والتتبّع (`/api/portfolio/track`).

الوضع العام **جيد نسبيًا**: 404 موحّد، عزل حالة الاشتراك عن العرض العام، تنقية الملف العام من الحقول الحساسة. لكن توجد مشاكل: **مفتاح اللغة غير متسق في الميتاداتا**، **نطاق خاطئ في صورة OG**، **تتبّع غير موثوق على Vercel (خامل بالذاكرة)**، و**قيود وصول قد تربك المستخدم المجاني**.

---

## 2) آلية العمل (تتبّع المسار)

- الملف العام: `src/app/u/[username]/page.tsx`
  - `getPublicProfile` مُغلّف بـ`cache()` — نداء واحد لكل طلب (السطر ~14).
  - يعيد `null` (→ 404 موحّد) إن لم يوجد المستخدم، أو لم يُنشَر، أو خُفي إداريًا: `if (row.status !== 'PUBLISHED' || row.adminHidden) return null` (السطر ~35).
  - تنقية العام: `toPublicProfile` (`src/lib/public-profile.ts`) تُزيل `userId/status/adminHidden/version`.
  - اشتراك لا يمنع العرض العام: تعليق صريح + منطق `isFree` (`page.tsx`).
  - إزالة الأقسام المقفلة للمجاني: `stripLockedSectionsForFree` (`src/lib/free-sections.ts:16`).
- صفحة المشروع: `src/app/u/[username]/projects/[slug]/page.tsx`
  - 404 موحّد لأنواع المشاريع غير المرئية (`isPortfolioVisible`).
  - **صفحات تفاصيل المشروع Pro فقط:** `if (!canViewLockedSections(sub.state)) return null` (~السطر 39) → المجاني لا يمكنه عرض صفحات المشاريع حتى لو كانت مربوطة.
  - لا تُعرض الصفحات غير المربوطة برابط (`referenced` check).
- التتبّع: `src/components/portfolio/TrackBeacon.tsx` (إرسال fire-and-forget، dedupe عبر `sessionStorage`) → `src/app/api/portfolio/track/route.ts` (تحديد معدّل بالذاكرة 60/دقيقة + اشتقاق الدولة/اللغة) → `src/lib/visits.ts` (استثناء زيارات المالك، تشفير IP).
- SEO: `src/app/sitemap.ts` (500 ملف + 500 مشروع كحد أقصى)، `src/app/robots.ts` (يسمح `/` و`/u/`، يمنع `/profile/`, `/api/`, `/admin`)، وصورة OG ديناميكية `src/app/og/route.tsx`.

## 3) المشاكل المرصودة

### 🟠 متوسطة — تتبّع غير موثوق على Vercel (خسارة بيانات تحليلات)
**مؤكد (تصميم) / مرجّح (أثر عملي).** تحديد المعدّل داخل `track/route.ts` يبدو **خاملًا بالذاكرة** (in-memory). على Vercel/serverless، كل نسخة (instance) لها ذاكرتها الخاصة، فالحالة لا تُشارَك بين الطلبات المتفرقة.
**الأثر:** قد تُقبل طلبات أكثر من الحد، أو تُرفض بشكل غير متسق → أرقام تحليلات المستخدم غير دقيقة. (الحد 60/دقيقة/عنوان IP.)
**الإصلاح:** استخدام مخزن مشترك (DB/Redis/KV) أو الاعتماد على dedupe الموجود في `visits.ts` بدل عدّاد الذاكرة.

### 🟠 متوسطة — عدم تطابق لغة الميتاداتا (SEO/مشاركة)
**المؤكد.** `contentLocale` تقرأ `appearance['defaultLanguage']` (`src/app/u/[username]/page.tsx:49-51`) بينما البنّاء يكتب `appearance.n`. النتيجة: `og:locale` = `en_US` دائمًا (`page.tsx:69`).
**الأثر:** مشاركة الملف العربي تظهر بميتاداتا إنجليزية.
**الإصلاح:** توحيد المفتاح مع البنّاء (`n`).

### 🟡 منخفضة — نطاق خاطئ في صورة OG (صقل/علامة)
**المؤكد.** التذييل يطبع `portholiohub.pages.dev` (`src/app/og/route.tsx:56`) بدل النطاق الحقيقي `portfolio-hub.online`.

### 🟡 منخفضة (خسارة عمل/ارتباك) — قيد Pro على صفحات تفاصيل المشروع
**المؤكد.** `canViewLockedSections(sub.state)` يمنع عرض صفحة المشروع للمستخدم المجاني (`projects/[slug]/page.tsx:~39`)، حتى لو أنشأها وربطها. **الأثر:** مستخدم مجاني ينشئ صفحة مشروع ثم يجدها لا تُفتح علنًا → ارتباك/انطباع "معطّل" (إن كان ذلك مقصودًا تجاريًا، فيُفضّل توضيحه في الواجهة).

### 🟡 منخفضة — عدد استعلامات لكل زيارة
**مرجّح.** `visits.ts` يُنفّذ عدة عمليات لكل مشاهدة (فحص dedupe ثم update/create)، وصفحة الملف تضيف `getSubscriptionState` لكل طلب. مقبول حجمًا لكنه تراكم قابل للتحسين.

### 🟡 منخفضة — حدود الـSEO ثابتة
**المؤكد.** `sitemap.ts` يحدّ الخريطة بـ500 ملف + 500 مشروع. عند تجاوز ذلك لا تُفهرس بقية الملفات.

### 🟢 معلوماتي — نقاط قوة (للتوثيق)
- 404 موحّد يمنع تمييز "غير موجود" عن "غير منشور" عن "مخفي" (حماية خصوصية).
- `toPublicProfile` تُزيل الحقول الحساسة.
- `robots.ts` يمنع `/profile/`, `/api/`, `/admin`.
- `TrackBeacon` لا يكسر الصفحة عند فشل التتبّع، ويحترم `sessionStorage`.

## 4) رحلة مستخدم عمره 17 سنة (زائر/صاحب ملف)

1. صاحب الملف ينشر → يشارك `/u/username` → الصفحة تُعرض (حتى المجاني).
2. يفتح صفحة مشروع تفاصيل → **مجاني: 404** (Pro فقط) → ارتباك إن لم يُوضّح.
3. زائر يشاهد → `TrackBeacon` يرسل ping → التتبّع قد يكون غير دقيق (خامل).
4. مشاركة على واتساب → صورة OG تحمل نطاقًا قديمًا ولغة إنجليزية.

**الحكم:** التجربة العامة **تعمل** مع 404 آمن؛ العيوب الأبرز: ميتاداتا لغة/نطاق، وتتبّع غير دقيق، وقيد Pro غير المشروح.
